## Estructura del Proyecto
- `index.html`: Maquetación principal accesible (WCAG) y navegación SPA.
- `css/styles.css`: Estilos visuales, modo alto contraste y soporte responsivo.
- `js/accesibilidad.js`: Control de contraste, tamaños de letra y síntesis de voz.
- `js/auth.js`: Matriz de validación de datos (VD-01 a VD-09, VD-23, VD-24) y roles.
- `js/vacantes.js`: Búsqueda, filtrado y gestión de ofertas laborales.
- `js/ui.js`: Controladores de interfaz, menú, chat y contacto.
- `js/app.js`: Orquestador principal de inicialización.
